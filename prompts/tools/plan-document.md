Create, update, read, or list planning documents while the workflow is in plan/read-only mode.
Documents are confined to `.adnify/plans/` and cannot modify source code. Use this for actionable
implementation plans, architecture notes, migration checklists, and decisions that should survive
the current response. Prefer the current session id as the stable document name.
