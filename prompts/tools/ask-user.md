---
id: ask-user
name: Ask User
category: interaction
riskLevel: safe
---

Ask the user one to three short decision questions using the bottom-dock choice tabs.
Use this only when the answer materially changes the implementation and cannot be inferred safely.
Each question must have two or three mutually exclusive options with concise descriptions.
The user navigates with arrow keys and confirms with Enter; never ask them to type an option number.
